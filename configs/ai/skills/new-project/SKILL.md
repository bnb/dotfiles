# new projects

unless the project says otherwise: Node.js, TypeScript, SvelteKit with Svelte 5, shadcn-svelte, Vite, Vitest with `@vitest/coverage-v8`, Playwright, Storybook, Lighthouse, oxlint and oxfmt, and pino for logs. Electron apps use Electron Forge. Rust TUIs use ratatui.
